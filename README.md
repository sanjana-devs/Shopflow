# ShopFlow — E-commerce Storefront

ShopFlow is a frontend e-commerce project built with HTML, CSS and JavaScript. It displays product information from a public API and provides basic shopping cart functionality.

**Project status:** In Progress

## Features

- Fetches product data from the DummyJSON API.
- Displays product images, names, categories, descriptions, prices and ratings.
- Dynamically generates product cards using JavaScript.
- Allows users to add products to a shopping cart.
- Tracks product quantities and calculates subtotals.
- Displays the total price of items in the cart.
- Includes loading and error messages when fetching products.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- [DummyJSON Products API](https://dummyjson.com/products)

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

An internet connection is required to fetch product data from the API.
